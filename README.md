# 🎓 PVC Co-Curricular Repository - Chandigarh University

A centralized online repository designed for the Academic Affairs (Co-Curricular Activities) department at **Chandigarh University**, providing easy access to essential official forms, guidelines, and documents for both students and faculty.

## 📌 Project Overview

The PVC Co-Curricular Repository simplifies the process of accessing, downloading, and submitting co-curricular documentation. It reduces the time and effort needed to locate various forms by hosting them on a single, responsive platform.

## 🌐 Live Website

[Visit the Repository Website](https://pvcco-curricularrepo.netlify.app/) 

## 🛠️ Features

- 🗂️ **Organized Document Repository**: Categorized sections for quick access to official documents.
- 📄 **Easy Downloads**: One-click download feature for forms and files.
- 📱 **Responsive Design**: Works seamlessly across desktops, tablets, and mobile devices.
- 🔍 **User-Friendly UI**: Clean and intuitive layout with quick navigation.
- 🎞️ **Dynamic Carousel**: Highlights important announcements and notices.
- 🔎 **Search Functionality** *(optional)*: Find documents quickly (can be added if needed).
